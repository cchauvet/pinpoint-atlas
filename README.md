# Pinpoint Atlas

A tap-the-map game for learning where the world's countries are.

**Play:** https://cchauvet.github.io/pinpoint-atlas/

On iPhone: open the link in Safari, tap the Share button, then **Add to Home Screen**. It opens full-screen like an app and works offline.

Map data: Natural Earth (public domain). Fonts: Atkinson Hyperlegible and Bricolage Grotesque (SIL Open Font License).
